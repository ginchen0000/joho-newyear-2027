# JÒHŌ HOTEL 跨年夜 V3
純靜態網站，無需安裝依賴。將本資料夾內所有檔案（含 assets）上傳至 GitHub repository 根目錄。Settings → Pages → Deploy from a branch → main → /(root) → Save。
本機可直接開啟 index.html。入口 index.html；版面及動畫 style.css；四語言文案、料理與互動 app.js；插畫 assets/。
首頁為靜態手繪插畫加 CSS 蒸氣及光影動畫，人物未獨立動畫。料理圖從已確認的設計稿裁切，並非實際出餐照片。故事人物為虛構；翻譯與料理內容待飯店確認。正式發布前請實機測試 iOS/Android。
